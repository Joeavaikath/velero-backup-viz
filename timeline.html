Backup Timeline

Shows what runs in parallel during a backup and what depends on what. Click any bar to see its dependencies and relationships.

Reading the chart

Horizontal axis = relative time. Each row = one concurrent activity. Dashed arrows show dependencies: one activity can't start until another finishes.

Colored callouts mark key moments: HANDOFF between controllers, BLOCKS where one thing waits on another, PARALLEL where things run independently.
